### ED-11.1 Toggle a breakpoint in the gutter or with F9
- Tag: both
- Evidence: source
- Boundary: no
- What: Click the glyph margin to add a breakpoint on that line. Hovering shows a faint hint dot with "Click to add a breakpoint". Clicking an existing breakpoint removes it, or turns a disabled one back on. Shift click flips enabled and disabled. F9 does the same for the cursor line. It works only where a debugger exists for the language, unless you allow breakpoints everywhere.
- Commands: editor.debug.action.toggleBreakpoint; debug.enableOrDisableBreakpoint
- Menus: MenubarDebugMenu
- Keys: F9 (when editorTextFocus or the disassembly view is focused)
- Settings: debug.allowBreakpointsEverywhere

## Unclear
- What ED-11 really holds: three unrelated families that share only the fact that they draw inside the text editor. Debug is 25 features (ED-11.1 to ED-11.25, with the floating toolbar in 17 to 19 partly outside the editor area), comments is 8 (ED-12.1 to ED-12.8) and test decorations is 5 (ED-13.1 to ED-13.5). Recommendation: split it into ED-11 Debug in the editor, ED-12 Comments in the editor and ED-13 Test decorations in the editor, because each has its own source folder, settings and extension dependency. Do it now, before the feature ids are used by later tools. If you keep one group, rename it "Debug, comments and tests in the editor". Confidence: medium - the split is cleaner but costs two more group ids and the three groups are small.
- Bookmarks: not present. There is no editor bookmark feature in stock 1.128.0, in the 1.144.0 clone, or in the Cursor bundle (only the codicon named bookmark and the Browser editor's bookmark bar, which is ED-10).
- Comment features (ED-12.1 to ED-12.8) show only when an extension provides a comment controller. Neither stock's built-in extension folder nor Cursor's has one that does (the Copilot review extension in the stock source tree is chat). The UI is core workbench code and is in Cursor's bundle.
- Debug features need a debug adapter. Cursor ships `ms-vscode.js-debug` and `ms-vscode.js-debug-companion` as built-in extensions, so the editor parts work for JavaScript and TypeScript; their own views were left out earlier by the catalog.
- Nothing was run on screen. Cursor evidence is ids, labels and module names in the bundle. Where I wrote "present" for a whole feature I searched at least one id or label of it; I did not check every row of every menu.
- Whether Cursor shows the debug toolbar in the command center slot (`debug.toolBarLocation` value `commandCenter`) was not checked.
- Newer than 1.128: I compared the folder listings for debug, comments and testing in the 1.144.0 clone and found no extra files, so nothing here is marked newer-than-1.128. Their contents were not diffed.

- Split on 2026-10-25: comment features moved to ED-12 (ED-11.26 to ED-11.33 became ED-12.1 to ED-12.8), test marks to ED-13 (ED-11.34 to ED-11.38 became ED-13.1 to ED-13.5). The first Unclear item above describes the group before the split.
