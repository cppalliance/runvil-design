### ED-12.1 Comment thread widget in the editor
- Tag: both
- Evidence: source
- Boundary: no
- What: A comment thread opens as a box in the text, under the commented line or range. It has a header with a Collapse arrow, the comments (author, avatar, time, rendered markdown), a reply box, and action buttons that the providing extension adds. Neither stock nor Cursor ships a built-in comment provider, so it shows only when an extension supplies threads.

- Settings: comments.maxHeight; comments.collapseOnResolve
- Cursor: present - widget modules (commentThreadZoneWidget, commentThreadWidget, commentThreadHeader, commentThreadBody) and the settings found; no built-in extension in Cursor calls the comment controller API

### ED-12.2 Add a comment from the gutter or by key
- Tag: both
- Evidence: source
- Boundary: no
- What: Where a provider allows comments, a "+" shows in the line gutter as you hover a commenting range. Click it to open a new-comment box. Drag along the gutter to cover several lines. "Add Comment on Current Selection" does the same from the keyboard. Some providers also allow a comment on the whole file. If the cursor is outside a commenting range it says "The cursor must be within a commenting range to add a comment."
- Commands: workbench.action.addComment
- Menus: CommandPalette
- Keys: Ctrl+K Ctrl+Alt+C (when activeCursorHasCommentingRange)
- Settings: comments.visible
- Cursor: present - id, label and error strings (nls 5204, 5205, 5217) found
- Source: V\src\vs\workbench\contrib\comments\browser\commentsController.ts; V\src\vs\workbench\contrib\comments\browser\commentsEditorContribution.ts; C bundle (modules comments/browser/commentsController, commentsEditorContribution)

### ED-12.5 Collapse a thread, with a warning if a reply is unsent
- Tag: both
- Evidence: source
- Boundary: no
- What: Escape in a comment box or on a focused comment collapses the thread; Ctrl+Escape (Alt+Backspace on Windows) collapses every visible thread from the editor. If the thread holds unsent text, a dialog says "Collapsing a comment thread will discard unsubmitted comments. Do you want to collapse this comment thread?" with a "Never ask me again" choice.

### ED-12.6 Move between comment threads and commenting ranges
- Tag: both
- Evidence: source
- Boundary: no
- What: Alt+F9 and Shift+Alt+F9 jump to the next or previous comment thread. Alt+F10 and Shift+Alt+F10 jump to the next or previous commented range.
