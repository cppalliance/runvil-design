### ED-10.1
1. Opening a PNG, JPG, GIF, WebP, SVG, ICO, BMP or AVIF file shows it in the Image Preview editor, scaled to fit the window.
2. Clicking the image zooms in one step.
3. Ctrl+click (Alt+click on Mac) zooms out one step.
4. Ctrl+wheel (Alt+wheel on Mac) or a pinch gesture zooms the image in and out.
5. While Ctrl (Alt on Mac) is held the pointer shows a zoom-out cursor, and otherwise it shows a zoom-in cursor.
6. `imagePreview.zoomIn` and `imagePreview.zoomOut` show in the Command Palette only while an Image Preview is the active editor, and each zooms the image one step.
7. Clicking the zoom entry in the status bar opens a "Select zoom level" picker listing 1000%, 500%, 200%, 100%, 50%, 20% and Whole Image, and picking one applies it (`_imagePreview.selectZoomLevel`).
8. The image keeps its zoom level and scroll position when you switch to another tab and come back.
9. If the image cannot be loaded the editor shows "An error occurred while loading the image." with an "Open file using VS Code's standard text/binary editor?" link that reopens the file as text.
10. A file that is only a Git LFS pointer shows "The image is stored with Git LFS and is not available for preview." with the same link.
